Detail panel: Pattern, Timestamp & Options

When a user clicks a file row or "Configure," the left panel switches to settings with three tabs. Two variations for the Pattern tab. Click your preference.

A

One-click pattern switch, custom hidden behind "More"

Auto-detected pattern is shown as a large chip with match %. Alternative patterns are secondary chips. A "More patterns" link opens a searchable dropdown. Custom pattern editor is behind a "Write custom" link at the bottom. Default path: see the auto-detected pattern, maybe click an alternative, done.
