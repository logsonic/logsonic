Approach B refined: How to access per-file settings?

Three ways to reveal the pattern/timestamp/multiline config for the selected file. Click your preference.

A

Expandable toolbar below preview

The bottom toolbar shows compact chips for Pattern, Timestamp, Multiline. Click one to expand an inline panel that pushes the preview up. Everything stays in the right pane.

B

Detail panel replaces the file list

Click the file row or a "Configure" button and the left panel switches from file list to a settings panel for that file. Tabs: Pattern, Timestamp, Ingest Options. Click "Back to files" to return.

C

Popovers per setting group

Click "Pattern" to open a popover with pattern options. Click "Timestamp" for timestamp options. Each setting is an independent popover anchored to its chip. Minimal UI until needed, but many clicks to configure everything.
