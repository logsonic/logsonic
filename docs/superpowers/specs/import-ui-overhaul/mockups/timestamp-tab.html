Timestamp & Options tabs

The Timestamp and Ingest Options tabs in the detail panel. Click to approve or suggest changes.

A

Timestamp tab: Simple detected / overrides behind expand

Primary state: a large status badge (Detected/Ambiguous/Missing) with the resolved timestamp format. If ambiguous, a prompt to confirm. Year/month/day/timezone overrides are behind "Adjust timestamp" expandable. Only shown when needed.

B

Timestamp tab: Full builder visible by default

The timestamp builder tiles (Year, Month, Day, Timezone) are always visible as a grid. Each tile shows parsed value with color-coded provenance (green=read from log, amber=inferred). More config visible up front, but also more visual weight.
