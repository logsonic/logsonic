A

Options tab = 3 toggle groups. Import button at bottom of file list.

The Options tab shows three collapsible groups: Smart Decoder (on/off), Timezone Override (dropdown), Multiline Records (mode selector + regex input if custom). The "Import N files" button lives at the bottom of the left panel (file list), always visible as a sticky footer. Options are set per-file; batch apply is available.
